# Real-world import corpus

Drop **real failing CV files** here to extend the import truth benchmark.

Supported: `.pdf`, `.docx`, `.doc`, `.png`, `.jpg`, `.jpeg`, `.txt`

Each file is imported through the browser product path and measured in `REAL_WORLD_IMPORT_TRUTH_REPORT.md`.

Named overrides (e.g. `pdf_canva.pdf`) also plug into the **18-file benchmark pack** — see `REAL_CV_BENCHMARK_PACK_REPORT.md`.

```bash
npm run real-world-import-truth-report
npm run real-cv-benchmark-pack-report
```
