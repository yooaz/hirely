# Hirely Landing Page — V4 Redesign Spec

**Version:** `LANDING_PAGE_V4`  
**Status:** Spec (replaces embedded hero + generic marketing in `index.html`)  
**References:** Linear · Arc · Perplexity · Raycast · Apple  
**Goal:** A **product-first landing** that shows what Hirely actually does — real CV transformations, not SaaS marketing — and gets users into import in one click.

---

## 1. Problem

The current landing (`#hero` in `index.html`) is functional but **generic**:

| Today | Issue |
|-------|-------|
| Badge + headline + 4-step pipeline cards | Reads like every CV SaaS |
| `trustTemplates20`, multilingual trust pills | Feature checklist, not proof |
| Pricing block below fold | Competes with primary CTA |
| No live product demo | User must upload to believe |
| `heroMorph` CSS exists but unused in markup | Missed transformation story |
| i18n strings mention “10k users” patterns in locales | **Banned in V4** — no fake social proof |

Hirely’s differentiator is **document transformation** — messy PDF in, recruiter-ready A4 out. The landing should **show that**, not list features.

---

## 2. Design north star

Borrow restraint and hierarchy from five references — not their aesthetics wholesale.

| Reference | What we take | What we skip |
|-----------|--------------|--------------|
| **Linear** | Tight type, monochrome, scroll-linked product frames, no clutter | Dark-only theme |
| **Arc** | Personality in micro-copy, bold focal color on one element | Browser chrome metaphor |
| **Perplexity** | One input, instant result, demo before signup | Search-bar layout |
| **Raycast** | Speed cues, keyboard hint, command clarity | macOS-only framing |
| **Apple** | Hero = product, large preview, generous whitespace, motion with purpose | Full-bleed video loops |

**Hirely V4 identity:** *Document studio* — warm off-white canvas (`--ds3-bg`), ink typography, A4 preview as hero visual, motion only on CV rebuild.

---

## 3. Remove (explicit ban list)

These patterns are **out of scope** for V4. Delete or never add:

### 3.1 Generic SaaS sections

| Section | Why removed |
|---------|-------------|
| 3-column “How it works” with icons | Replaced by **animated rebuild** |
| Logo wall (“Trusted by…”) | No enterprise logos unless real partners |
| Testimonial carousel | Use **real transformation captions** instead |
| “Why Hirely?” feature grid (8+ cards) | Max **3 proof moments**, not 8 features |
| FAQ accordion (12 questions) | Max 4 questions; link to docs |
| Blog / resources teaser | Out of scope |
| Comparison table vs competitors | Out of scope |

### 3.2 Fake statistics

**Never display** unless sourced from real analytics dashboard:

- “10,000+ CVs improved”
- “98% interview rate”
- “4.9/5 from 2,000 reviews”
- “Used by Google, Meta, …” (unless contracted)

**Allowed metrics** (only when true and live):

- Real extraction retention % from demo run
- Real recruiter score delta on showcased fixture
- “Free to start” / “No account required” — factual product facts

### 3.3 Feature overload

| Cap | Rule |
|-----|------|
| Hero | 1 headline + 1 subline + 1 primary CTA |
| Proof sections | Max 3 on page |
| Nav items | 3: Product · Examples · Pricing |
| Footer links | Max 6 |

**Badge line:** One clause only — e.g. `CV import → recruiter-ready PDF` — not `CV premium · audit · templates · export · score · AI`.

Each showcase must cite **concrete deltas** from actual engine output:

| Delta type | Source engine | Example caption |
|------------|---------------|-----------------|
| Sections detected | `SECTION_ENGINE_V2` | “6 sections structured from 1 text block” |
| Text retention | `extraction-report` | “94% of source text preserved” |

| Template | `cv-templates.js` | “Rendered in Art Director Portfolio” |

**Forbidden:** Hand-written “after” copy that wasn’t pipeline-generated.

### 4.3 Interactive demo

**Perplexity pattern:** Try before upload.

| Mode | Behavior |
|------|----------|
| **Demo CV** (default) | Pre-loaded fixture — no file required |
| **Your CV** | Existing upload flow |

**Demo selector:**

```
┌─────────────────────────────────────────────┐
│  Try Hirely — no upload needed              │
│  [ Designer CV ▾ ]  [ Run demo ]            │
│                                             │
│  ┌─ Live workspace (read-only) ─────────┐   │
│  │  Import ✓ → Review → Template → PDF  │   │
│  │  [A4 preview updating in real time]  │   │
│  └──────────────────────────────────────┘   │
│  [ Import my CV ]  ← converts to real flow  │
└─────────────────────────────────────────────┘
```

**Implementation:**

- `src/ui/landing/demo-runner.js` — runs canned `structuredResume` through preview render
- Fixtures: `designer-cv-rich`, `mvp-sample`, `portfolio-links-rich`
- Demo mode: `?demo=designer` deep link
- No API keys; client-side only (same as production import)
- CTA handoff: “Import my CV” clears demo state, focuses `#drop`

**Raycast touch:** `⌘K` or `/` opens demo picker (optional Phase 2).

---

### 4.4 Animated CV rebuild

**Hero centerpiece** — replaces static 4-step pipeline cards.

**Arc + Linear motion:** One looping sequence (~8s, pauses on hover, respects `prefers-reduced-motion`).

```
Stage 1 (0–2s)     Messy document drops in — skewed PDF, OCR noise
Stage 2 (2–4s)     Blocks extrude — sections label in (Experience, Skills…)
Stage 3 (4–6s)     Layout rebuild — columns snap to single column
Stage 4 (6–8s)     Template skin applies — A4 shadow, typography upgrade
Stage 5 (hold)     Score ring counts 54 → 78
```

**Visual spec:**

| Element | Treatment |
|---------|-----------|
| Container | `heroRebuild` — max-width 520px, `--ds3-shadow-cv` |
| Before card | Off-axis −2°, noise overlay, `JetBrains Mono` snippet |
| After card | Aligned 0°, full A4 ratio 1:1.414 |
| Connector | Morph path (SVG) or crossfade — not cheesy 3D flip |
| Labels | Micro caps, `--ds3-tracking-kicker` — Linear style |

**Modules:**

- `src/ui/landing/hero-rebuild-animation.js`
- `src/ui/landing/hero-rebuild-animation.css`
- Reuse: `hirely-wow-factor.css` tokens, `cvSkBlock` skeleton stagger

**Fallback (reduced motion):** Static before/after split image from showcase manifest.

```

hirely-wow-factor.css        ← motion hooks
```

### 7.2 New tokens

```css
:root {
  --landing-bg: var(--ds3-bg);
  --landing-hero-min-height: min(88vh, 920px);
  --landing-showcase-ratio: 1 / 1.414;
  --landing-accent: #111110;          /* single accent — ink */
  --landing-accent-glow: rgba(17,17,16,.08);
  --landing-before-bg: #ececea;
  --landing-after-shadow: var(--ds3-shadow-cv);
}
```

### 7.3 Color discipline (Apple)

- Background: warm gray `#f3f3f1`
- Text: ink hierarchy only — no purple gradients
- Accent: one CTA fill — ink black
- Success delta: `--green` only for score +N

### 7.4 Motion budget

| Animation | Duration | Easing |
|-----------|----------|--------|
| Hero rebuild loop | 8s | `cubic-bezier(.4,0,.2,1)` |
| Tab crossfade | 280ms | ease |
| Score count-up | 1.2s | `hirely-wow-factor` existing |
| Scroll reveal | 400ms | opacity + 12px Y |

`prefers-reduced-motion: reduce` → all loops off, static frames.

## 11. Accessibility

- Hero animation: `aria-hidden="true"` on decorative rebuild; text alternative in `aria-label`
- Showcase tabs: proper `role="tablist"` / `aria-selected`
- Demo: does not trap focus; keyboard reachable CTAs
- Reduced motion: full static fallback
- Contrast: WCAG AA on all text (ink on `--ds3-bg`)
